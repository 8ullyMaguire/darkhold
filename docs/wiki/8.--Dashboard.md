In order to visualize the recommendations made by our algorithm and some of the more relevant graphs an interactive dashboard was created using [dash](https://plotly.com/dash/). This dashboard will allow you to load your recommendations and visualize them in more detail than the one provided by the output of the different scripts. 

In order to run the dashboard the first step is to acquire the files needed and put them in the proper format. A script called format_files.py is provided in the dashboard folder that will serve this purpose. Keep in mind that the files generated by this script need to be found in the same folder where your app.py script is found. If the files are not there the dashboard will not work.

To run the format_files.py mode into the 8_dashboard folder and type:

`cd 8_dashboard/`

`python3 format_files.py -i metadata_fics.clean.txt -t user2item.txt -b best_results.txt -r best_results.item2item.txt`

Where the -i option asks for the metadata file, the -t requires the user to item table, the -b option asks for the set of user to item recommendations that you want to include in the dashboard whereas the -r takes the item item recommendations. The user2item table added can be any of the ones generated, in the example I will add the training set because the whole set is cumbersome due to its size. The recommendations I add were obtained by applying the best model I found in matrix factorizaton with implicit to the complete dataset and then extracting the user to item and item to item recommendations.

To see the dashboard, you only need to execute the app.py script after generating the proper files. Keep in mind that the dashboard needs a set of proper files to work. This means you should not move it from its location. The only file that was not included to make it work out of the box is the metadata file due to its size. You can either move it inside the folder or you can give the path with the -i option.

`python3 app.py -i metadata_fics.clean.txt`

Once the script is executed it will remain active as long as you want to interact with it, if you want to stop it just press control+c. To access the dashboard follow the link provided when executing python3 app.py (it should be similar to http://127.0.0.1:8050/). This will open a window in your navegator that will look like this:

The dashboard is divided in two sections. The upper section contains the recommender. It allows you to select which recommendation you want to explore and then allows you to input a user or item name. When no user or a new user are given the table will show the fics with the largest amount of likes. This was the non-personalized recommender that worked the best in our training dataset. The input for the item search should be the id rather than the title of the fic, as the title may not be unique. The id of a given fic can be easily found when visualizing the link: https://archiveofourown.org/works/**1948845**

The lower part of the dashboard contains a set of interactive graphs that will allow you to explore some of the characteristics and results from the recommender system. The graph you will see in the first place shows the final metrics of the different methods and a brief explanation on what the dashboard is about. All graphs are interactive and you information will be shown when hovering the mouse over it. Additionally you can select a part of the graph if you want to have a closer look. A double click will take you back to the main view. Note that some of the graphs load a lot of information so they will take a few seconds to load.
